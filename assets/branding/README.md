# Branding Assets

This directory contains only approved public-facing visual assets. The `zynex-github-social-preview.png` file is the branded 1280 × 640 social-preview image referenced by the showcase README. It contains only the public ZYNEX name, tagline, and high-level capability words; no user data, credentials, payment information, or internal URLs are present.

To configure it as the GitHub repository social preview, open the repository’s **Settings → General → Social preview** and upload the approved 1280 × 640 PNG. Do not upload screenshots, proprietary design source files, or any image containing user data, credentials, private URLs, or internal infrastructure details.
