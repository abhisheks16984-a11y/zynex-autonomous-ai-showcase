# Security Policy

## Scope

This repository contains public documentation and sanitized showcase material. It does not contain the ZYNEX production application or operational credentials.

## Reporting a security concern

Use this repository’s **Report a vulnerability** feature to submit a private GitHub security advisory. That report is visible only to the reporter and repository maintainers during triage.

Do not publish suspected vulnerabilities, screenshots containing private data, API keys, access tokens, credentials, or proof-of-concept payloads in public issues, pull requests, discussions, or comments. If the private advisory workflow is unavailable, use the official contact route published on [zynexai.co](https://zynexai.co/) to request a private reporting channel.

## What to include

Provide a concise description of the issue, the affected public surface, safe reproduction steps, impact, and any suggested mitigation. Do not include real user data, secrets, active credentials, or destructive payloads.

## Response expectations

Reports are reviewed privately. Disclosure timing, remediation, and acknowledgments are coordinated with the reporter when appropriate. No response-time guarantee is made in this public showcase policy.

## Public contribution rules

Never submit secrets, private customer information, production environment files, payment-provider credentials, private certificates, or deployment configuration. If a contribution accidentally includes sensitive content, stop and contact the maintainers through a private channel before opening a pull request.

## Supported material

Security fixes for this public documentation repository may be reported. Production application vulnerabilities are handled through the private product-security process.
