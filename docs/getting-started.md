# Getting Started with the Showcase

This repository is documentation-only. It is not a local-development package and does not contain the ZYNEX production source code, environment configuration, or deployment setup.

To explore ZYNEX, visit [zynexai.co](https://zynexai.co/). To contribute to the showcase, begin with [CONTRIBUTING.md](../CONTRIBUTING.md) and confirm that any proposed material is public-safe.
