# Contributing

Thank you for improving the ZYNEX public showcase. Contributions are limited to documentation, public-safe diagrams, sanitized examples, and approved visual placeholders.

Before proposing a change, confirm that it does not reveal proprietary source code, credentials, internal endpoints, user information, deployment configuration, payment details, or unpublished roadmap commitments. Keep claims evidence-based and mark planned work clearly.

## Suggested workflow

Create a focused branch, make the documentation change, check Markdown links and Mermaid syntax, and explain why the contribution is public-safe. Do not add runtime dependencies or executable production code to this showcase repository.

## Required checks

Every contribution must preserve `.gitignore`, avoid committing environment files, and respect [SECURITY.md](SECURITY.md) and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
